Set a password

The web UI is locked until you set a password. Set the environment variable named in server.password_env (default RADAR_UI_PASSWORD), then restart radar serve.

If your network already controls who can reach Radar (Tailscale, a LAN-only address, or an authenticating proxy), you can set server.ui_auth: none instead.

Feedback links in your digest emails work either way.
